# An Agentic Toolkit and Comparative Study for HPC Operations and User Support

High-performance computing (HPC) centers are facing a period of rapid change. System architectures are increasingly heterogeneous, software environments evolve quickly, and workflows now span traditional simulation, large-scale data analysis, and AI-driven methods. At the same time, user populations are growing and diversifying, while expectations for responsiveness and reliability continue to rise. These trends place sustained pressure on operations and user support teams, who must diagnose complex failures, navigate fragmented information sources, and maintain service quality at scale.

Recent advances in large language models (LLMs) and agentic AI systems—where models are coupled with tools, memory, and control logic—offer a promising path to augment HPC operations. In principle, such systems can synthesize documentation, query operational data sources, triage user tickets, and assist with incident response. In practice, however, deploying agentic AI in HPC environments raises several open questions: How should agents be structured to balance flexibility and reliability? What are the tradeoffs between lightweight tool-augmented workflows and more autonomous agents? How do open-weight models compare with proprietary frontier models on realistic HPC tasks? And how should performance be evaluated in terms that matter to operations teams, such as latency, cost, and task success?

This paper presents ATHOS, an open, model-agnostic agentic toolkit for HPC operations and user support, together with a comparative study of agent designs, models, and frameworks on realistic HPC evaluation tasks. Rather than positioning ATHOS solely as a production system, we use it as an experimental platform to systematically explore design choices in agentic AI for HPC centers. The goal is to provide both a reusable toolkit and empirical guidance for practitioners considering similar deployments.

ATHOS is designed around a modular, registry-driven architecture that allows agents to be composed from interchangeable components: language models, tool interfaces, orchestration logic, and evaluation harnesses. The toolkit emphasizes configuration over customization, enabling the same workflows to be executed with different models (open-weight or proprietary), agent frameworks such as SmolAgents and LangChain/LangGraph, and tool backends without rewriting core logic. ATHOS integrates with common HPC operational systems—such as job schedulers, allocation and quota services, and ticketing platforms—through standardized tool interfaces implemented using the Model Context Protocol (MCP), enabling agents to ground their reasoning in live operational data.

A central contribution of this work is an evaluation framework and dataset suite tailored to HPC operations. We curate and structure several classes of evaluation tasks derived from real operational workflows, including: (1) knowledge-oriented question answering grounded in HPC documentation and policies; (2) user support scenarios involving job failures, misconfigurations, and resource usage questions; and (3) site reliability engineering (SRE) tasks such as incident summarization, trend identification, and cross-system diagnosis. These tasks are encoded as reproducible test cases with reference outcomes, allowing controlled benchmarking across agent configurations.

Using this framework, we conduct a comparative study across multiple dimensions:

- Agent and tool design: We evaluate single-step tool-augmented workflows versus multi-step planning agents, as well as varying degrees of autonomy and human-in-the-loop control. Results highlight cases where simple, constrained designs outperform more flexible agents in reliability and latency, and cases where richer planning is essential for task completion.
- Model selection: We compare open-weight large models—including GPT-OSS–class models—with proprietary frontier models such as the latest Claude and GPT families on the same tasks, measuring accuracy, robustness, latency, and token cost. This analysis provides concrete data to inform tradeoffs between cost control, performance, and deployability in HPC environments.
- Agent frameworks: We benchmark implementations built using SmolAgents and LangChain/LangGraph, examining differences in expressiveness, overhead, and ease of integration with HPC tooling.

Evaluation metrics include task success rates, graded quality scores, end-to-end latency, and token consumption, reflecting both qualitative effectiveness and operational cost. Where appropriate, we report variance across runs to capture stochastic behavior. Importantly, we emphasize metrics and failure modes that are meaningful to operations teams, rather than generic NLP benchmarks.

We report results from early deployments and experiments conducted at NERSC, using operational integrations inspired by production environments on systems such as the Perlmutter supercomputer. While ATHOS is not presented as a fully autonomous production system, these experiments demonstrate realistic workflows and surface practical considerations around security, access control, and trust.

Our findings suggest that agentic AI can meaningfully augment HPC operations and user support when designs are carefully constrained and evaluated. In particular, we observe that: (1) tool grounding and task structure can matter as much as raw model capability for many operational tasks; (2) open-weight models can be competitive on well-scoped support tasks when paired with effective tools; and (3) evaluation infrastructure is essential for avoiding over-engineering and for making informed design decisions.

We conclude by discussing implications for deploying agentic systems in HPC centers, lessons learned from early experimentation, and directions for future work. These include expanding evaluation datasets, integrating additional operational data sources, and exploring adaptive agents that adjust their autonomy based on task complexity and risk. More broadly, this work aims to contribute a shared experimental foundation for the HPC community as it explores AI-assisted operations, moving from ad hoc prototypes toward evidence-based, trustworthy deployment.
